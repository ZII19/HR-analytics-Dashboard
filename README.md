# HR-analytics-Dashboard
Developed an interactive dashboard in Power bi to analayze the employee attrition ,workforce demographics &amp; salary distribution etc.
This dashboard enables HR teams to monitor key workforce metrics and make data-driven decisions to improve employee engagement and retention.

Tools & Technologies Power BI DAX Power Query Excel Data Modeling

Key Features Attrition Analysis Employee Count Tracking Department-wise Attrition Insights Salary Distribution Analysis Age Group Analysis Job Satisfaction Metrics Interactive Filters and Slicers KPI Cards and Drill-through Reports DAX Measures Used Attrition Rate Employee Count Average Salary Retention Rate Active Employees

Business Insights Generated Identified departments with the highest attrition rates. Analyzed employee retention patterns across age groups and job roles. Evaluated salary distribution and workforce demographics. Provided insights to support workforce planning and employee engagement strategies.

Outcome The dashboard provides HR stakeholders with a centralized view of workforce performance and employee retention metrics, enabling faster and more informed decision-making.
